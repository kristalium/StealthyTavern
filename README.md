For all people paranoid or in environments that are not that appropriate for the RP - StealthyTavern. To hide your stuff.

Features:
* Change browser tab title to whatever you want. Google Docs by default.
* Change tab icon to anything. Google Docs by default.
* Toggle to block all images: from avatars to in-chat.
